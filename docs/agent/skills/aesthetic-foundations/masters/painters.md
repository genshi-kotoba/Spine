# 绘画大师 — 作为视觉判断的参照系

不是要学画画, 是借**他们的眼睛**看你的设计.
"Vermeer 会怎么处理这里的光?" "Mondrian 会保留这条分隔线吗?"

每位大师有一个**核心招数**, 把那一招记牢即可.

---

## Vermeer (1632-1675) — 单光源的窗

**招数**: 单一光源 (通常左上方窗户) + 极度安静的构图.

**为什么神**:
- 整张画只有一束光, 但因为它**唯一**, 它就强大无比
- 人物 + 桌上物品 + 墙面挂画构成几何方块, 严密但不冷
- 蓝 (lapis lazuli, 当时极贵) + 黄 (Naples yellow) 是他的招牌色对

**应用到设计**:
- 一个页面**只要有一个"光源"** (主焦点 + 主对比), 它就有秩序
- 不要 3 个 hero 区, 选 1 个加强, 其他降级
- 极致的"安静感"靠**减法** — 减掉所有不必要的装饰, 留下的几个元素自然显得珍贵

**作品**: *The Milkmaid* (倒奶的女工, 极致单光源), *Girl with a Pearl Earring*, *The Music Lesson*

---

## Mondrian (1872-1944) — 不对称中的平衡

**招数**: 红 / 黄 / 蓝 + 黑线网格. 每个色块**位置和大小都经过计算**, 整体非对称但完美平衡.

**为什么神**:
- 从树木风景画一路抽象到纯色块 (1908-1920 是渐变过程, 看他的进化是审美教育)
- 大红块在右下, 小蓝块在左上, 黑线把画面切成不对称区域 → 张力 → 解决
- **平衡 ≠ 对称**: 这是 Mondrian 教的核心一课. 对称是稳定但死板, 不对称平衡是动态稳定.

**应用到设计**:
- Layout 不需要左右对称. 左侧大区域 + 右侧小区域可以平衡, 只要视觉权重相等
- 用网格做结构, 但允许元素**跨网格** (Mondrian 的线分割不均匀)
- 强色 (品牌色) 不要均匀分布, 集中在 1-2 个位置, 占面积小但视觉重

**作品**: *Composition with Red, Blue and Yellow* (1930), *Broadway Boogie Woogie* (1942-43, 后期密集版)

---

## Rothko (1903-1970) — 色块即情绪

**招数**: 几个大色块 + 模糊的边缘 + 巨大尺寸 (3 米高) → 观众站在画前被淹没.

**为什么神**:
- 颜色之间的**边缘羽化**很关键 — 不是硬边, 而是软渗透 → 像呼吸
- 同一色系不同饱和度 (深栗 + 红橙 + 朱) → 单色系最高境界
- 尺寸是作品的一部分 — 印刷品 (A4) 完全感受不到原作 (3m) 的压迫感

**应用到设计**:
- 用色块情绪可以替代大量文字 — landing page hero 一大块深色调 + 极简文字 > 满屏说明
- 边缘软化 (subtle gradient / blur) 在数字界面少见, 但用得好高级感强
- **尺寸是表达** — 一个 H1 不应该总是 32px, 给特殊页面用 64-96px

**作品**: *No. 14, 1960* (深红蓝), *Black on Maroon* (黑暗系列)

---

## Hopper (1882-1967) — 孤立 + 都市光

**招数**: 美式 1930s 都市场景 + 大块平直墙面 + 几个人物孤立在空间里 + 强方向光.

**为什么神**:
- 构图大量留白 (空墙面, 空街道), 人物挤在画面角落 → 视觉张力
- 光是**有形状的** — 一道斜光打在墙上, 形状本身就是构图元素
- 情绪: 孤独 / 等待 / 城市疏离 — 全靠**没说出口的留白** 传达

**应用到设计**:
- 把主体放在画面**角落或边缘**, 而不是中心, 制造"未完成感" / "正在发生"
- 大块单色空间 (墙面 = 整片米底 / 整片深底) 比花哨纹理更有力
- 留白是情绪载体 — 不是"信息没填满", 是"信息有意不填"

**作品**: *Nighthawks* (1942, 夜餐厅, 最有名), *Early Sunday Morning*, *Automat*

---

## Sargent (1856-1925) — 减法是创作

**招数**: 看似随意的笔触, 实际**每一笔都精确**. 别的地方留作空白 / 暗示.

**为什么神**:
- 肖像画极其精准 (一笔下去脸的结构出来), 但服装 / 背景常常**只有几道色块**
- 重点画得"满", 次要部分**只暗示** — 用户大脑自动补全
- 用最少的笔触传达最多 — 这是大师和工匠的差别

**应用到设计**:
- 主要内容**完全表达** (大字标语清晰 + 主图细节充分)
- 次要内容**只点到为止** (metadata 用最小字号最浅灰, 用户需要才看)
- 不要"装饰式平等" — 所有元素都打磨到极致 = 主体反而显不出来

**作品**: *Madame X* (1884), *Carnation, Lily, Lily, Rose* (1885-86, 灯笼系列)

---

## Hokusai / Hiroshige — 浮世绘平面构图

**招数**: 没有西方透视, 用**斜线 + 平面色块** 制造空间感. 取景极致大胆 (前景一片树叶, 远景一座富士山).

**为什么神**:
- 影响了 Van Gogh, Monet, Manet, Whistler — 整个印象派的源头
- 框中框 (frame within frame) 大量使用 — 透过门 / 树 / 浪 看到主体
- 极少阴影 (东方画法), 全靠**轮廓 + 平面色** 构图

**应用到设计**:
- 大胆裁剪 — 主体不必完整, 切一半反而更动 (头像图片的紧裁剪)
- 平面 (Flat Design) 不是 2010s 美国发明的 — 浮世绘已经做到极致
- 前景 + 中景 + 远景 的层次, 用尺寸和位置区分, 不一定要用阴影

**作品**: 北斋 *富岳三十六景* (1830-32, 神奈川冲浪里), 广重 *东海道五十三次*, *名所江户百景*

---

## 八大山人 (朱耷, 1626-1705) — 极少笔, 极大张力

**招数**: 一只鱼 / 一只鸟在大片空白里, 鱼眼翻白看天 → 整张画的孤独感扑面.

**为什么神**:
- 极简到不能再减 — 一只鸟可能只有 5-6 笔
- 鸟 / 鱼的"眼神" 是画的核心 — 翻白眼 = 朱耷的招牌, 表达"看不起这个世界"
- 大量留白不是"没画完", 是**主角** — 那片空白是水 / 天 / 孤独

**应用到设计**:
- 单一元素**居中浮在大量留白**里 → 极强表达
- 不要害怕"信息太少" — 一屏一个核心信息 + 大量空气, 用户记得住
- 表达情绪的关键在"细节" — 鸟的眼神 = 设计的一个**意外细节** (一个手绘 icon, 一个不规整的边缘)

**作品**: *Lotus and Bird*, *Fish and Rocks* (各种鱼鸟系列)

---

## Monet — 印象派的色彩感知革命

**招数**: 同一主体在不同时刻 / 光线下画一系列 (Rouen Cathedral 30 多张), 揭示**光不是固定的, 物体的颜色随光变**.

**为什么神**:
- 引出"色彩相对论" — Albers 后来系统化 (参 [color.md §2 Albers](../references/color.md))
- 大笔触 + 视觉混色 (近看是色点, 远看混合) → pointillism 后来发扬
- 教会人"看 = 时刻在变" — 这种观察力是审美训练的核心

**应用到设计**:
- 调色不在调色板上, 在**实际使用环境**里调 (深色模式 / 浅色模式 / 不同显示器)
- 颜色不是"绝对值", 是"在这个背景下的感受"
- 系列美学 — 一个产品在不同状态 (空 / 加载 / 成功 / 失败) 应有视觉一致性而非个别处理

**作品**: *Rouen Cathedral 系列* (1892-94), *Water Lilies 系列* (1899-1926)

## 怎么用这些大师

**不是模仿风格**, 是**借判断力**.

设计一个 dashboard 主区域时, 问自己:
- Vermeer: "这里的'光'(焦点) 在哪? 唯一吗?"
- Mondrian: "这个不对称 layout 平衡了吗?"
- Sargent: "metadata 是不是太重了? 砍掉一半试试?"
- 八大山人: "如果我把所有装饰都减掉, 主体能撑住吗?"

每个大师是一种**专门的眼睛**. 多个眼睛交叉看, 设计就高了一档.
