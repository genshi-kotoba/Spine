# 构图 — 视觉结构的基本工具箱

绘画 + 摄影 + 设计共用的"如何放东西"语法.

---

## 1. 视觉权重 (Visual Weight)

每个元素都有重量 — 由 **大小 × 对比 × 饱和度 × 复杂度 × 位置** 综合决定.

| 因子 | 加重 | 减轻 |
|---|---|---|
| 大小 | 大 | 小 |
| 明度对比 | 强 (深底白字) | 弱 (灰底浅字) |
| 饱和度 | 鲜艳 | 灰 |
| 细节密度 | 文字密 / 图复杂 | 简单形状 / 空白 |
| 位置 | 上 / 左 (中文阅读起点) | 下 / 右 |
| 孤立度 | 周围留白 = 加重 | 挤在元素堆里 = 减重 |

**核心: 一个画面只能有一个最重的元素**. 两个一样重的元素 → 视觉拉锯 → 看不下去.

应用: 一个页面看不出"先看什么", 通常是 3+ 元素权重打平. 修法: 给 1 个加重 (放大或加色), 其它**降级**.

---

## 2. 三分法 vs 居中 vs 黄金比

**三分法 (Rule of Thirds)**: 画面横纵各分三段, 主元素落在交点或线上.
- 来源: 摄影常用法则, 因为均衡但不死板.
- 适用: 想要动态的、有呼吸感的构图.
- 反例: 证件照、对称仪式感构图、产品包装正面 — 这些**居中更对**.

**居中 (Centering)**: 仪式、权威、稳定、神圣.
- 文艺复兴祭坛画、宋瓷开光纹饰、Apple keynote 单图、log-in 表单.
- 信号: "这件事很重要, 看它".

**黄金比 (φ ≈ 1.618)**: 三分法的精致版.
- 主元素放在画面 0.618 处.
- 字号 / 间距 阶梯比也常用 φ (16 → 26 → 42).
- 不要迷信 — 三分法 95% 情况已够用, 黄金比是想要"刻意精致"时用.

**动态对称 (Dynamic Symmetry)**: Jay Hambidge 系统化的黄金矩形分割, 文艺复兴和 Bouguereau 的隐藏构图脚手架. 工程上太学院, 知道存在即可.

---

## 3. 视觉路径 (Eye Path)

眼睛在画面上是**有路径**的, 不是均匀扫. 设计是引导这条路径.

**典型路径**:
- **Z 形**: 西文阅读默认 — 左上 → 右上 → 左下 → 右下. 适合宣传海报 / 头图 / dashboard 一屏.
- **F 形**: 长文 / 列表 — 第一行扫到底, 第二行扫一半, 后面只扫开头. 列表设计永远把关键字段放最左前.
- **S 形 / 螺旋**: 绘画常用 — 从一角进入, 蜿蜒到画面中心. Bouguereau / Rubens 巨幅油画的招牌. 设计上用于"故事性 landing page".
- **中心向外**: Mandala 式. 极少在 UI 用, 出现在 logo / 仪式页.

**引导线 (Leading Lines)**: 物理或心理上的线, 引导眼睛.
- 物理: 道路、墙线、河流 (摄影), 分隔线 (UI).
- 心理: 人脸朝向 — 人物朝哪边看, 观众的目光跟过去. 应用: 在头图把人物朝向往 CTA 方向布.

**消失点**: 透视画里所有平行线汇聚的点 — 通常落在主体上, 强化聚焦. UI 等同物: 多个对齐元素的视觉延长线交汇处.

---

## 4. 三分 / 四分 / 五分割

**横向布局节奏**:
- **二分**: 对峙 / 对话 / 对照. 易僵, 慎用 (除非是对照 UI).
- **三分**: 主 + 次 + 装饰 (黄金三角). 摄影最常.
- **奇数 > 偶数**: 3 个元素比 4 个动. 5 比 6 动.
- **四分**: 方块格栅 / 工具页 / 数据 dashboard — 是工程美而非动态美.

---

## 5. 正负空间 (Figure-Ground)

经典 Rubin 杯 vs 脸 — 同一个画面, 主体与背景可互换.

**好的构图**: 负空间 (背景) 也有形状美感, 不只是"主体周围的填充".

**审美训练**: 看一张构图时, 把眼睛聚焦在**空白处**而不是主体, 问"这片白形状好不好看?"
- 好: 空白是流动的、有动势的、像一个独立形状
- 坏: 空白是切碎的小条 / 不规则窄缝

UI 上等同: 卡片之间的 gap / 主区域和侧栏之间的空白 — 如果那个空白形状难看, 整页就难看.

参 [ma-and-negative-space.md](ma-and-negative-space.md) 深入.

## 6. 紧张与解决 (Tension & Resolution)

好构图通常有一对**不平衡的张力 + 解决张力的元素**.

- Mondrian: 大红块拉到角落 (张力) + 几条黑线穿过 + 一个小蓝块平衡 (解决).
- Hopper *Nighthawks*: 巨大空旷夜街 (张力: 孤立) + 玻璃后那一群人 (解决: 但又不解决, 余韵).
- 优秀 landing page: 大字标语 + 一个意外细节 (一个手绘画在文字旁) — 张力是文字严肃, 解决是手绘人性化.

平淡 = 没张力. 慌乱 = 张力没解决.

---

## 7. 重复与变奏 (Repetition & Variation)

- **完全重复**: 网格阵列 — 工业感、秩序、稳定. 适合数据表、商品列表.
- **重复 + 一个例外**: 节奏感最强的构图. 9 个同款卡片中一个用不同色 → 那一个变焦点.
- **完全无重复**: 杂乱 / 拼贴 / 信息超载. 慎用.

**Vignelli 法则**: 重复是节奏的源泉. 一篇文档只用 2-3 种字号, 不是 6 种.

---

## 8. 摄影特有 — 框中框 (Frame within Frame)

把主体放在画面里**另一个框架**之内 (门、窗、拱、镜中镜) — 用第二层框强化焦点 + 增加深度.

布列松大量用此招. UI 等同: 卡片套卡片 (modal in modal — 慎用), 或主图区域有内嵌的强对比区块.

---

## 9. 跨域映射 (绘画 → UI)

| 绘画概念 | UI 等同 |
|---|---|
| 视觉权重 | 元素的"看到先后" |
| 引导线 | 阅读顺序 / 路径设计 |
| 消失点 | 主 CTA / 焦点元素 |
| 负空间 | 卡片间距 / margin 形状 |
| 框中框 | modal / 嵌套卡片 |
| 张力 + 解决 | 主标语 + 副标语 / 主图 + 标注 |
| 重复 + 例外 | 列表 + 特殊状态卡片 |

---

## 10. 反审美陷阱

- **均匀填满**: 每个角落都塞东西, 没空气. 修法: 删 30%.
- **多焦点**: 3+ 元素抢主角. 修法: 选 1 个升级, 其余降级.
- **僵硬对称**: 完美对称 = 死板 (除非是仪式页). 修法: 微破对称 (放 1 个偏移元素).
- **路径断裂**: 用户看完头图后不知道下一步看哪. 修法: 加引导线 (箭头 / 分隔线 / 头图人物视线方向).
