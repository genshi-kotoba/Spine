# 摄影大师 — 框定与瞬间

摄影教的是**怎么看世界, 怎么裁剪世界**. 这两件事对设计同样核心.

---

## Henri Cartier-Bresson (1908-2004) — 决定性瞬间

**招数**: "Decisive Moment" (决定性瞬间) — 在 1/125 秒内, 几何 + 故事同时完美的那一刻按下快门.

**为什么神**:
- 跟踪几何**预判**人物会走到哪个交点 — 不是抓拍, 是预谋
- 每张作品里能找出**清晰的几何构图** (三角 / 平行 / 对角)
- 黑白, 35mm Leica, 不剪裁 (取景已经完美就不需要后期)

**经典: 巴黎雨后水洼**
- 一个人正要跳过水洼, 一脚悬空 — 那个 1/125 秒
- 几何上: 人的姿态镜像在水中倒影 → 上下对称
- 故事上: 还没落地, 充满悬念

**应用到设计**:
- 设计 = 选择**那一帧** (按钮 hover 哪个时刻最像 hover? loading 哪一帧最有期待?)
- 几何和故事**同时**满足 = 高分. 只满足几何 = 装饰, 只满足故事 = 杂乱
- 不要后期剪裁 — 设计 mockup 一次到位, 不要"先做出来再裁"

## Richard Avedon (1923-2004) — 隔离主体

**招数**: 白色无缝背景 + 人物正面 + 极强光 → 把主体从所有上下文里**剥离**.

**为什么神**:
- 不依赖环境讲故事, 完全靠主体本身的细节 (皱纹 / 眼神 / 姿态) 讲
- 极简 = 最难, 因为没东西藏 — 任何瑕疵都暴露
- 大尺寸打印 (1.5m+ 人脸) → 观众被迫直视

**经典: In the American West (1979-1985)**
- 美国西部蓝领工人系列, 全部白底, 5x7 大画幅
- 当时震惊 — 蓝领 + Avedon 的"时尚摄影"风格 = 提升劳动者尊严

**应用到设计**:
- 隔离 = 强调 — 把主体放在大量白空间里, 比加粗加大都更强
- 不要"用环境装饰主体" — 摆个花瓶 + 一个 placeholder 设计 = 主体看不清
- 移除背景纹理 / 装饰 → 主体自然跳出 (Apple 产品摄影一直这个套路)

## Saul Leiter (1923-2013) — 抽象的街头

**招数**: 1950s 纽约街头, 透过雨水玻璃 / 镜面反射 / 半遮挡前景拍照 → 街景变抽象油画.

**为什么神**:
- 西方街头摄影的"反主流" — 别人追"清晰", 他追"模糊"
- 颜色**低饱和度** + 局部高饱 → 整体安静, 一点醒目
- 视角永远是"窥视" — 从遮挡里看, 不是直面

**应用到设计**:
- 大面积低饱 + 一点高饱 = 高级感的色彩节奏 (参 [color.md Itten 第 6 对比](../references/color.md))
- 部分遮挡的元素比完全展现的更有戏剧性 (carousel 把第二张露半个边)
- 模糊 / 半透明 是数字设计里被低估的工具 (Apple "frosted glass" 效果学自此)

## 杉本博司 Hiroshi Sugimoto (b. 1948) — 时间作为曝光

**招数**: 极长曝光 (一整场电影的时间 = 一张照片) → 影院屏幕变成纯白方块.

**为什么神**:
- *Theaters* (1976-): 在电影院支三脚架, 整部电影曝光 → 屏幕过曝成白, 影院建筑细节出来 → "时间被压缩成一帧"
- *Seascapes*: 海平线系列, 全球 200+ 海点, 每张构图相同 (海平线在画面中央) — 极简到极致
- *Architecture*: 故意失焦, 建筑只剩轮廓

**经典: Seascapes**
- 海平线把画面分成上下两半, 上海下天 (或反过来), 100% 灰度调
- 每张几乎一样 — 但每张都不同 (光 / 雾 / 微风)
- 极简的"系列美学"

**应用到设计**:
- 简化到极致, 但每个变体仍有可辨细节 (Apple 产品页, 每个产品一张图一个标题, 但不一样)
- 留白可以是**主体** (海平线作品里那片灰白海面 = 主角)
- 时间作为维度 — UI 的 transition / loading 状态是"设计的另一帧"

## Stephen Shore (b. 1947) — 平视, 平淡, 是美

**招数**: 1970s 美国公路旅行系列, 拍**最平凡的东西** (停车场 / 汽车旅馆 / 早餐桌) — 但用极致严谨的构图.

**为什么神**:
- "Banal as form" — 主题平庸不重要, 形式才重要
- 8x10 大画幅 + 一丝不苟的水平垂直对齐 + 中央构图 → 一个停车场看起来像古典油画
- 颜色: 1970s Kodachrome 色彩 — 略偏暖, 怀旧但不刻意

**经典: Uncommon Places (1973-1979)**

**应用到设计**:
- 不必"主题宏大" — 一个 dashboard 数字卡片用心做, 跟 hero landing 一样有美感
- 严谨的对齐 + 平淡的内容 = 视觉魅力 (Notion 的简洁页面学的这个)
- 不必加滤镜 / 风格化 — 内容到位 + 构图严谨, 自然好看

## Vivian Maier (1926-2009) — 街头中的偷瞄

**招数**: 1950-70s 芝加哥保姆, 用 Rolleiflex (低头取景器, 别人看不见在拍) 拍街头 → 完全自然的瞬间. 生前默默无闻, 死后被发现.

**为什么神**:
- 低视角 (相机在胸前) → 仰视人物, 自带尊严
- 黑白对比强烈, 几何感清晰
- 自拍系列 (镜中 / 影子) 是身份探索

**应用到设计**:
- 视角 = 设计的隐藏维度. 同样的内容, 仰视 / 平视 / 俯视效果不同 (照片 hero, header logo 大小, 字体 weight 都是"视角"决策)
- 不引人注意 = 自然 (UI 的微动画 / 状态切换若被用户察觉到, 反而失败 — 应该"看不见地"完成)

## Andreas Gursky (b. 1955) — 大尺寸的工业全景

**招数**: 极大画幅 (3m × 5m) + 数码后期合成 + 全景视角 → 工业 / 商业的庞大、重复、非人.

**为什么神**:
- *99 Cent* (1999): 美国 99 美分超市内景, 货架延伸到无穷远, 颜色饱和如波普 → 是消费主义的肖像
- *Rhine II* (1999): 莱茵河 + 草地 + 天空 + 几条水平线 → 极简风景, 卖了 430 万美元
- 用规模制造威严

**应用到设计**:
- 整齐重复 + 巨大尺寸 = 视觉冲击 (商品列表页, 数据网格)
- 后期可以加工 (设计本质是后期) — 不必"完全真实"
- 极简风景 (Rhine II) vs 极满消费 (99 Cent) 都对 — 取决于讲的是什么

## 怎么用这些摄影大师

设计一个**主图 / hero / 视觉焦点** 时:
- Bresson: "几何和故事同时完美吗?"
- Avedon: "主体周围是否够干净? 能不能再剥离一层?"
- Leiter: "大面积低饱 + 一点亮色, 这个比例对吗?"
- 杉本博司: "能不能再简一档?"
- Shore: "对齐够严谨吗? 平凡内容也能美."

摄影教的两件事永远适用设计:
1. **取景** — 决定**什么进 / 什么出**, 即裁剪 / 删除
2. **时机** — 决定**这一帧**, 即状态选择
