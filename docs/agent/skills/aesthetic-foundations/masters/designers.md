# 平面 / 工业设计大师 — 系统化的审美

设计师不像画家 / 摄影师靠"灵光一现", 他们的招数是**可重复的系统**.
学他们 = 学怎么把审美**变成方法论**, 这样能反复出好作品.

---

## Dieter Rams (b. 1932) — 工业设计 10 诫

德国, Braun 首席设计师 (1955-1995), 影响 Apple 整个工业线 (Jony Ive 直言).

### 10 Principles of Good Design

1. **Innovative** — 创新, 但服务功能, 不为创新而创新
2. **Useful** — 有用, 卖的是功能, 不是花样
3. **Aesthetic** — 美, 但来自简洁与诚实
4. **Understandable** — 自解释, 不需要说明书 (产品本身 = 说明书)
5. **Unobtrusive** — 不喧哗 — 工具不是艺术品, 是用户表达的延伸
6. **Honest** — 诚实, 不假装比实际更强 / 更贵 / 更智能
7. **Long-lasting** — 经得起时间, 不追时尚
8. **Thorough down to the last detail** — 细节彻底, 不能"差不多就行"
9. **Environmentally friendly** — 环保
10. **As little design as possible** — **Less, but better.** (越少越好, 但是更好)

### 标志性作品
- Braun T3 收音机 (1958) — Apple iPod 设计原型
- Braun SK4 录音机 (1956) — "Snow White's Coffin", 白色透明罩
- 606 Universal Shelving System (1960) — 还在卖, 60 年没过时

### 应用到 UI / 数字设计

- "Less but better" 不是"删 50%", 是"留下的每件事都必须**真有用**"
- 工具产品不应炫技 — 你的代码编辑器不应有星空背景动画 (那是干扰)
- "诚实" — loading 状态应显示真实进度, 不要假进度条
- 每个像素 / 每个文字都问"它在帮用户还是在炫我"

## Massimo Vignelli (1931-2014) — 网格 + 极少字体

意大利 / 美国, 设计了 NYC 地铁图, AA 美航 logo, Knoll 家具品牌, *Vignelli Canon* (免费 PDF, 必读).

### 招数

- **一辈子只用 6-8 种字体**: Helvetica, Bodoni, Garamond, Times, Optima, Futura, Century Expanded
- 极严的网格系统 — 每件作品都有 underlying grid
- **不接受装饰** — "设计是智力工作, 不是表演"

### 经典: NYC Subway Map (1972)

- 把纽约地铁画成**几何抽象** — 所有线路 45° / 90°, 不是真实地理
- 每条线一个色码, 站点是圆点
- 极简到普通市民看不懂 (因为没有地理参照), 后来被换成 "geographic" 版
- **现在公认是 20 世纪最伟大的信息设计之一** (虽然乘客不喜欢)

### Vignelli Canon 核心论点

1. **Discipline** — 一致性是设计的核心力量
2. **Appropriateness** — 适配场景比"原创"重要
3. **Ambiguity** — 拒绝模糊, 一切清晰
4. **Visual Power** — 视觉力来自简洁, 不来自装饰
5. **Intellectual Elegance** — 智力优雅 > 视觉花俏
6. **Timelessness** — 拒绝跟随潮流
7. **Responsibility** — 设计师对社会有责任

### 应用到 UI

- 一个项目 **2-3 个字体家族足够** — Newsreader + Inter + JetBrains Mono 是 Vignelli 准则的现代体现
- 严格的间距 / 字号集合 (8 个值的 spacing scale)
- "信息设计师 vs 装饰设计师" — UI 设计是信息设计

## Jan Tschichold (1902-1974) — 两次转向都对

德国排版师, 写了两本影响深远的书, 立场**完全相反**.

### Phase 1: Die Neue Typographie (1928)

- 拒绝古典对称 → 走非对称、几何、Sans-serif、左对齐
- 这本书是 Bauhaus / 包豪斯 排版的圣经
- 当时震撼

### Phase 2: Penguin Composition Rules (1947)

- **完全转向, 回归古典对称 + Serif + 居中**
- 设计 Penguin Books 全线封面 — 严谨的古典排版, 一套规则贯穿数百本书
- 这套规则现在仍是出版业标杆

### 教训

- 没有"唯一正确"的排版 — 看**项目语境**
- 一个设计师能**深入两种相反的传统**, 才是真大师
- 不要陷入"风格教派"

### 应用

- 营销 landing 用非对称 + sans (Phase 1 的现代主义)
- 文学项目 / 长文 / 学术站用古典对称 + serif (Phase 2 的古典回归)
- **同一个项目内的不同区** 可能要不同处理 (营销页 vs 文档页)

## Saul Bass (1920-1996) — 大胆简化 + 概念

美国, 设计了 Anatomy of a Murder, Vertigo, Psycho 电影海报, 也做企业 logo (AT&T, United Airlines, Bell).

### 招数

- 海报 = **一个核心 visual idea** + 极简执行
- 大胆色块 + 撕裂感几何 + 手写体
- Logo = 一个**形状即概念** (AT&T 的地球线条, Bell 的钟形)

### 经典作品

- *Vertigo* 海报 (1958) — 螺旋图案 + 红黑色块, 一眼传达"眩晕 / 不安"
- *Anatomy of a Murder* (1959) — 撕裂的人形, 立刻有"谋杀 / 解剖"
- AT&T 球形 logo (1983) — 简单几条曲线传达"全球通讯"

### 应用

- 复杂概念用**一个 visual metaphor** 传达 — 设计的核心工作之一
- 不要"内容堆叠" — 选最关键的 1 件事强化
- 海报式思维 (一屏一概念) 在现代 web hero 章节仍然适用

## Ellen Lupton (b. 1963) — 当代美国 typography 教学

策展人 (Cooper-Hewitt), 教师 (MICA), 著 *Thinking with Type* (typography 入门教科书).

### 核心论点

- **Type is language given form** — 字体是语言被赋予的形体
- 排版 = 一种"声音"的视觉化 — 字体选择、字距、layout 都在告诉读者"用什么语气读这段"
- 现代 typography 应该**有性别 / 文化意识** — 不是"客观中立"的工具

### 应用

- 不同语境用不同字体声音:
  - 严肃 / 学术: serif + 紧凑字距
  - 友好 / 现代: humanist sans + 适度行高
  - 工具 / 工程: mono + 等宽数字
- 排版**不是装饰**, 是"怎么读"的元信息

## 原研哉 Hara Kenya (b. 1958) — MUJI / 空 / 触觉

日本, MUJI 艺术总监 (2002-), 著 *Designing Design*, *White*.

### 招数

- **"白" 不是颜色, 是状态** — 一种"未完成 / 可能性 / 静默" 的状态
- 设计应**减到只剩感觉** — 一个杯子不必有花纹, 它的形状 + 重量 + 温度就是设计
- **触觉、嗅觉、声音** 都是设计语言, 不只有视觉

### 经典:
- MUJI 整个品牌语言 — 不命名 (无印良品 = "无品牌"), 不装饰, 强调材料本身
- 2003 *Re-Design* 展览 — 把日常物件 (卷纸 / 火柴 / 茶包) 重新设计, 在功能不变前提下"减"
- 长野冬奥会开闭幕式 (1998) 视觉

### 应用

- "空" 不是设计的对立面, 是设计的**核心材料**
- 不要"用 banner 填满空白" — 空白是设计师**有意创造**的, 不是"懒得填"
- 数字设计的"触觉" = 微交互 / hover / 过渡动画 — 是用户感受设计**温度**的入口

## Paula Scher (b. 1948) — 当代美国大胆排版

Pentagram 合伙人, 1990s 起在美国引领"巨大文字 + 几何切分" 风格.

### 招数

- 文字 = **图像** — 一段文字铺满版面, 不是阅读对象, 是视觉块
- 极大字号 + 多列错位 + 切角
- Public Theater (1995-) 系列海报, MoMA 重大展览

### 应用

- Hero 区不必"简洁文字 + 大配图" — 一行字本身就能是 hero
- 文字作为"画面" 而非"信息" — 在视觉冲击力强的场景下 (海报 / landing / 标语)
- 大胆 ≠ 凌乱 — Paula Scher 的版面虽然复杂, 但 underlying grid 极严

## 怎么用这些设计大师

设计**系统**时调:
- Rams: 10 诫第 10 — "less but better"
- Vignelli: 字体阶梯 / 间距阶梯 / 网格
- Tschichold: 项目语境是现代还是古典

设计**视觉传达**时调:
- Saul Bass: "一个概念, 一个 visual"
- Paula Scher: "文字能不能直接当画?"

设计**信息层级 / 触感**时调:
- Lupton: "这段排版的'声音'对吗?"
- 原研哉: "白 / 空 / 留白用对了吗?"

每个大师是一条**判断的路径**. 多条路径交叉, 你的设计就不再是"看心情画"了.
