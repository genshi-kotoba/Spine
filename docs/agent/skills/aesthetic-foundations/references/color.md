# 色彩 — 不是 hex 值, 是关系

色彩的核心不是"用什么颜色", 是**颜色之间的关系**. 单独一个 #4CAF50 没好坏, 放在 #F5F0E6 米底上是优雅, 放在 #00FF00 旁边是廉价.

---

## 1. 三维色彩模型 — Munsell

理解色彩必须用 3 个轴:

- **色相 (Hue)**: 红 / 橙 / 黄 / 绿 / 蓝 / 紫 — 色轮上的角度.
- **明度 (Value)**: 深 / 浅. 0 = 黑, 10 = 白.
- **饱和度 / 纯度 (Chroma)**: 灰 (0) → 鲜艳 (max). 同色相, 高 chroma = 鲜艳, 低 chroma = 灰调.

**为什么这 3 维都重要**:
- 同色相不同明度 → 是同一颜色家族, 但层级不同 (浅蓝 vs 深蓝).
- 同色相不同饱和度 → 鲜艳 vs 灰调 — 完全不同情绪 (鲜红 = 节庆, 砖红 = 沉稳).

**应用**: 设计 token 系统时, **明度阶梯比色相变化更重要**. ink → ink-2 → ink-3 → ink-4 应该是同一色相 (warm gray 或 cool gray) 的 4 个明度. 不要用"绿色 ink / 蓝色 ink" 这种色相替代法做层级.

## 2. Albers 的核心论点 — 色彩是关系

Josef Albers *Interaction of Color* (1963) 一句话: **没有绝对的颜色, 只有相对的颜色**.

经典实验:
- 同一块灰, 放在白底上看起来深, 放在黑底上看起来浅.
- 同一块橙, 放在棕底上 = 桃色, 放在粉底上 = 砖红.

**含义对设计**:
1. 你看的 hex 值不是用户看到的颜色 — 背景在变, 邻接元素在变, 同样的 hex 视觉感受不同.
2. 给颜色 "命名" (warning yellow, success green) 是危险的 — 命名固化了它在某个场景下的样子, 换场景就崩.
3. 在主屏上调色, 必须在**最终上下文**里调, 不在调色板里调.

## 3. Itten 的七对比 (Seven Color Contrasts)

Johannes Itten *The Art of Color* 列出 7 种基本色彩对比, 是色彩张力的基本素材:

1. **色相对比 (Hue Contrast)**: 不同色相并置 — 三原色组合最强 (蒙德里安红黄蓝).
2. **明暗对比 (Light-Dark)**: 深色配浅色. **最强的层级工具, 比色相对比可靠**.
3. **冷暖对比 (Cold-Warm)**: 蓝绿紫 vs 红橙黄. Vermeer 的窗光 = 冷的环境光 + 暖的人物肌肤.
4. **互补对比 (Complementary)**: 红 vs 绿, 蓝 vs 橙, 黄 vs 紫. 同时存在 → 互相加强饱和度, 易俗气 (圣诞红绿).
5. **同时对比 (Simultaneous)**: 互补色在感知里互相诱发 — 看红边时眼睛在边缘产生绿色微光.
6. **饱和度对比 (Saturation)**: 高饱 vs 低饱并置 — 高饱的会"跳出来". 大面积低饱 + 一点高饱 = Saul Leiter / 杨福东.
7. **面积对比 (Extension / Proportion)**: 暗色少 + 亮色多 vs 暗色多 + 亮色少 → 情绪完全不同. Itten 给比例公式 (黄:紫 = 1:3), 但**核心: 一种色少 = 它跳; 多 = 它沉**.

**应用**: 设计时**先决定用哪种对比**, 再选具体颜色.
- 信息层级 → 明暗对比为骨架
- 强调 / CTA → 饱和度对比 (一点高饱 vs 大面积低饱)
- 中性界面 + 一个 accent → 面积对比 (95% 中性 + 5% 强色)

## 4. 价值先于色相 (Value First)

这条是绘画训练最早教的一课, 也是设计师最常忘的一课.

**法则**: 先用灰度画一遍, 层次必须**已经成立**, 再上色. 颜色是后期装饰, 不是层级骨架.

**判别**: 设计稿截图 → Photoshop / 工具一键去色 (或 macOS 系统级 grayscale 滤镜) → 主标 / 副标 / metadata 还能分得清吗?

**反例 (失败)**: 标题 #2196F3 (亮蓝), 正文 #757575 (中灰), 警告 #F44336 (亮红). 灰度后亮蓝和亮红明度差不多, 标题和警告"打架".

**正例**: 标题 #1A1814 (极深 ink), 正文 #4A4640 (中 ink2), metadata #8C8780 (浅 ink3), 警告 #B85A3A (deep amber). 灰度后明度 4 级分明.

## 5. 限制调色板 (Limited Palette)

业余画家用 24 色, 大师用 6 色 (Zorn Palette: ivory black, yellow ochre, vermilion, titanium white — 4 色画一切).

**为什么少更好**:
- 强迫"用关系造层级", 不是"用更多色相"
- 整张画/页色调统一 (因为所有颜色都从相同的几个基色调出来)
- 易记 / 易复用

**UI 应用**: 一个完整设计系统**核心调色板 5-8 色就够**:
- 1 个 bg (warm cream / cool gray / 纯白, 3 选 1)
- 1 个 ink 家族 (3-4 个明度的 warm gray)
- 1 个 accent (primary action)
- 1-2 个 semantic (success / warn / error, 但通常只用 warn 和 error)
- 1 个 line / divider (浅一档的 ink)

**反例**: Material Design 默认 17 色 swatch — 给业余设计师"够用", 但给好设计师**太多**, 反而让结果俗气.

## 6. 暖中性 vs 冷中性

灰不只是"灰" — 灰有温度.

- **暖中性灰** (#F5F0E6 米底, ink 偏红/黄): 怀旧 / 手工 / 温暖 / Notion / MUJI / 中式书卷
- **冷中性灰** (#F0F0F2 冷底, ink 偏蓝/灰): 工业 / 科技 / 干净 / Apple / Linear / 工具

**选择的依据是项目语境**, 不是个人偏好.

---

## 7. 单色系 (Monochrome)

完全单色相 + 多明度 = 极成熟的方案.

- Rothko 后期: 一块深栗 + 一块红橙 + 一块朱红 — 都是红家族.
- 宋瓷 (青瓷 / 汝窑): 单一釉色, 但深浅层次极丰富.
- 现代 brutalist 网站: 黑白灰 + 一点 accent.

**适用**: 想要克制、深度、不喧哗.
**反例**: 数据 dashboard 不适合 — 状态色 (绿正常 / 黄警告 / 红错误) 是用户期望.

## 8. 色彩心理 (慎用, 文化相关)

通用的:
- 红: 注意 / 危险 / 节庆 (中) / 爱 (西)
- 蓝: 信任 / 工业 / 冷静
- 绿: 正常 / 自然 / 金钱 (美) / 嫉妒 (西)
- 黄: 提醒 / 阳光 / 警告
- 黑: 严肃 / 奢华 (西) / 哀悼 (东)
- 白: 干净 (西) / 哀悼 (东)
- 金: 财富 / 仪式

**别滥用**: "vc 投资页用蓝色 = 专业" — 这种刻板印象, 一抓一大把.

更好的问法: 这个**场景**需要什么情绪 → 找一个能承载的颜色 (不限于刻板印象).

---

## 9. 实操工具

- **灰度测试**: 去色看层级 (前述)
- **squint test**: 眯眼模拟饱和度面积关系
- **对比度检查**: WebAIM Contrast Checker (text 4.5:1, large text 3:1) — 不是审美但是底线
- **同时对比检验**: 给最终背景上调色, 不在调色板调
- **限制法**: 砍掉一半颜色看看, 通常更好

## 10. 反审美陷阱

- **彩虹色 badge**: 每种状态一种鲜艳色 — 视觉杂. 修法: 明度区分 + 1 个色相.
- **品牌色滥用**: 整页都是品牌主色 — 视觉疲劳. 品牌色应该是 5% 用量, 不是 50%.
- **用色相代替明度做层级**: 蓝色标题 + 红色 CTA — 灰度后一团. 修法: 明度阶梯, 色相只用在 accent.
- **饱和度爆炸**: 所有颜色都最饱和 → 廉价感. 高级感来自**大面积低饱 + 局部高饱**.
- **冷暖打架**: 暖底 (米色) 用冷蓝 ink — 不和谐. 暖底配暖 ink (warm gray), 冷底配冷 ink.
