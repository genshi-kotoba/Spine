# 中式审美 — 留白、气韵、计白当黑

中式审美的核心**不是装饰**, 是**节制与韵味**.
当项目是中文为主, 或想表达"东方克制 / 文人气", 应优先调这套, 而不是默认走 Bauhaus / Material.

中式审美和日式 ma 是**远亲不是同义**: 日式 ma 更接近"无", 中式留白更接近"虚中有韵".

---

## 1. 留白 — "计白当黑"

清代邓石如论书法: "计白当黑, 奇趣乃出." (邓石如《艺舟双楫》)

**意思**: 把白处当黑处一样**经营**. 不是"剩下的地方", 是和墨色同等重要的造型元素.

**例**:
- 书法字与字之间的白, 行与行之间的白, **是有形状的**, 形状错了整幅字就垮
- 画里大量空白 (云、雾、远水), 看似没画, 实则**整张画的气在那里**

**对设计的启示**:
- 卡片之间的间距形状美不美
- 主区域 + 侧边栏之间的"白带" 形状美不美
- 一个 hero section 上下大量留白 — 那块白是被**经营** 的, 不是"剩下"

---

## 2. 气韵生动 — 谢赫六法之首

南齐 谢赫《古画品录》(约 532 年) 提"六法":
1. **气韵生动** (最高)
2. 骨法用笔
3. 应物象形
4. 随类赋彩
5. 经营位置
6. 传移模写

气韵 = **作品自带的呼吸感、流动感、生命力**.

无法被分解成具体规则, 但能感觉到:
- 一幅好山水, 你"感觉到"风穿过画面
- 一段好书法, 你"感觉到"作者写字时的呼吸节奏
- 一个好 UI, 你"感觉到"它在邀请你, 而不是抗拒你

**对设计**:
- 元素之间的过渡 (微动画、hover、滚动) 应该顺势, 不卡顿 → 这是数字界面的"气"
- 单页节奏 (信息密集 → 一个大留白 → 信息密集) → 形成呼吸 → 是数字界面的"韵"
- 平淡的产品页 vs 一段有"气"的产品页: 内容一样, 但读完感受不同

---

## 3. 文人画 — 不为客户, 为自己

宋元起兴起的"文人画" (士大夫业余画家, 非职业画师):
- 不为卖钱, 不为皇室, 为**自娱**
- 强调**笔墨韵味** > 描绘技巧
- 题诗 + 印章 + 画三位一体, 画面里有"文学"
- 代表: 苏轼、米芾、倪瓒、董其昌

**核心精神**: 设计的最高目标**不是讨好用户**, 是设计师对作品自身的诚实表达. 用户能不能 get 不是最重要 — get 到的人会真懂.

**对当代设计**: 抗"用户测试驱动一切" 的工程主义. 用户测试是基线, **品味是天花板**. 完全依赖 A/B 测试只能做到平均水准, 不能做出"有性格的产品".

---

## 4. 倪瓒 (1301-1374) — 萧疏寒林

元四家之一, 极简文人画典型.

**招数**:
- 画**永远是同一个公式**: 近景三五寒树, 中景空旷江面, 远景几座淡山, 中部留一大片空
- 笔触干燥 (干笔皴), 几乎不上色 (淡墨)
- 画里通常**没有人** → 萧疏感

**核心**: 减到几乎不能再减, 但留下的每个元素**都不能动**. 动一个就垮.

**对设计**:
- 极简到"少一个元素就缺、多一个元素就乱"的临界点 — 那是好设计的标志
- 单色 / 接近单色的 palette → 可以极其有性格 (不一定要彩色才好看)
- "无人感" 适合: 工具型产品、文档站、专业站 → 不需要笑脸 illustration, 留白本身就是表达

---

## 5. 八大山人 (朱耷, 1626-1705) — 极少笔的张力

明末清初, 朱明遗族, 出家后以绘画寄孤愤.

**招数**:
- 极简 — 一只鱼 / 一只鸟 / 一片荷叶, 配大片留白
- 鱼鸟**翻白眼** → "不屑看这世界" → 招牌情绪
- 笔触少但每一笔都极有力, 没有犹豫
- 题款 / 印章构图巧妙

**对设计**:
- 一屏一个核心元素 + 大量留白 = 极强表达 (类似 Apple keynote)
- 表情 / 细节 = 设计的"翻白眼" — 一个意外的小细节让产品有性格 (一个 404 页的小创意 / loading 状态的一个小幽默)
- 用最少笔触做最强表达 — 这是"极简设计" 的真正难处

---

## 6. 宋瓷 — 单色釉面的深度

宋代官窑 / 汝窑 / 哥窑 / 钧窑 / 定窑 — 中式器物美学巅峰.

**招数**:
- 主流是**单色** — 青、白、月白、天青、米黄
- 釉面**有深度** — 单色但不是死板, 有层次 / 开片 (裂纹) / 釉滴变化
- 形态**极简** — 碗、瓶、盘, 不追新奇造型

**对设计**:
- 单色调色板 + 大量明度变化 = 高级感 (比"用三个品牌色" 更难)
- "细节在深度而非花样" — 单一颜色但有微妙渐变 / 纹理 / 边缘处理
- 形态用约定俗成 (经典 layout), 美感在**比例 / 间距 / 表面质感**

---

## 7. 园林 — 借景、对景、咫尺山林

中国园林 (苏州 / 杭州 / 北京) 的核心招数:

**借景** — 把围墙外的山 / 塔 / 树, 通过窗 / 门洞**框成构图的一部分**.
**对景** — 走过曲径, 转角看到对面亭子里的题字 → 走动中**看到新景**.
**咫尺山林** — 几平米院落, 一块石、几竿竹、一汪水 → 整座山林的味道.

**对设计**:
- "借景" = 现代 web 的 modal / 浮层 / iframe — 把外部内容引入当前视图
- "对景" = 多页面 / 多视图设计 — 用户每"转角" (路由跳转) 看到设计上有呼应的新景
- "咫尺山林" = 移动端设计 — 小屏不应"缩小桌面", 应**自己是一个完整的小世界**

---

## 8. 文房四宝 + 古玩雅趣 — 物的温度

**笔墨纸砚** + 书架上的雅玩 (玉、瓷、铜、玛瑙、印章、镇纸) → 文人书斋美学.

**特征**:
- **不追新** — 喜旧, 喜包浆, 喜使用痕迹
- 材料**自带温度** (玉 / 紫檀 / 端砚 / 宣纸)
- **不求完美** — 残缺、开片、做旧, 反而有韵味

**对设计**:
- 数字产品的"质感" 来自微细节 (毛玻璃、纸纹、磨砂、阴影微调)
- 不追"全新" — 老 logo / 经典字体在新设计里依然有效
- "做旧" 在数字上有边界 — 不要 skeuomorphism 过度 (iOS 6 的真皮笔记本 是反例)

---

## 9. 戏剧脸谱 / 民间剪纸 — 装饰的极致

另一极: **极满 + 极色 + 极图案化** — 民间美术的反极简.

**特征**:
- 京剧脸谱: 红 / 黑 / 白 / 黄 / 蓝 / 紫强对比, 大胆色块, 极致装饰
- 剪纸: 满构图, 没空白, 全是花纹
- 杨柳青年画: 大红大绿, 满版人物

**为什么这也是中式审美**:
- 中式审美**不是只有文人极简**. 民间美术是另一极, 同等重要
- 强对比 + 强图案 = 节日 / 喜庆 / 庶民审美
- 抽象到"符号化", 比西方写实更早进入"图案语言"

**对设计**:
- 不要把"中式 = 极简" 简化 — 节庆类、消费类、流量类用满版 / 大色块 是地道的
- 中式审美的**双重传统** (文人极简 + 民间装饰) 给设计提供**两条路径**

---

## 10. 中式审美的现代化困境

近 30 年中国设计常**误把"中式审美"= 加几个传统纹样**:
- 圆角配祥云
- 红黄主色 + 龙凤
- 福字 / 中国结贴上 → "中国风"

这是**装饰主义陷阱**, 不是中式审美.

**真正的中式审美**:
- 留白 / 节奏 / 气韵 (无形)
- 不是图案的"中式", 是判断力的"中式"

**好的现代化范例**:
- 原研哉 / MUJI (日本) — 不用中式纹样, 但精神是东方的
- 王澍 (建筑) — 不抄古建筑, 但空间感是中式的
- 民宿 / 茶室 设计师 — 留白 + 材料 + 比例, 没花纹但是中式

## 11. 怎么用中式审美做 UI

| 场景 | 借鉴谁 |
|---|---|
| 中文为主, 工具型 | 倪瓒 (萧疏) + 宋瓷 (单色深度) — 主色暖灰, 强对比文字, 大量留白 |
| 文学 / 文化项目 | 文人画 (题款 + 印章 + 画) — 用serif 中文 (思源宋), 严谨排版 |
| 节日 / 消费 / 流量页 | 民间美术 (剪纸 / 年画) — 大色块, 满构图, 但仍要有节奏 |
| 茶 / 物 / 慢生活类 | 园林 + 文房四宝 — 微细节、材料感、不刻意但有韵 |
| 开发工具 / 文档站 / 偏严肃 SaaS | 倪瓒 + 文房 — 暖灰底 + serif 标题 + 大量空气 |

---

## 12. 反审美陷阱

- **图案中式**: 加云纹、回字纹、祥云 → 装饰, 不是审美
- **大红大金**: 默认"中国风 = 红金" → 民间消费陷阱, 不是文人审美
- **强行毛笔字**: 用毛笔字体做按钮 → 不合场景
- **塞古诗**: 网站 footer 引用唐诗 → 矫情, 除非项目就是诗词主题
- **"中式" 是品味, 不是元素**: 没有具体元素也可以很中式 (留白 + 节奏 + 比例)

---

## 13. 一句话总结

> 中式审美的核心是**节制 + 韵味**.
> 节制 = 减到不能再减 + 每个保留的元素都不能动.
> 韵味 = 元素之间的关系、空白处的气、整体的呼吸感.

不是用什么颜色 / 什么图案. 是**判断力**.
